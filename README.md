# PaintELEMENTOR — випуски

Тут публікуються інсталятори програми PaintELEMENTOR (норми витрат ЛФМ за кресленнями КМД) і файл `latest.json`, за яким встановлена програма перевіряє оновлення.

- Встановлення вперше: завантажте `PaintELEMENTOR_<версія>_x64-setup.exe` з останнього випуску (Releases).
- Далі програма оновлюється сама: «Налаштування → Оновлення програми».
- Інсталятори підписані ключем розробника; програма ставить лише оновлення з правильним підписом.
